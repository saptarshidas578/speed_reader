# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Focus Reader Pro operates entirely as a client-side web application without a backend server or persistent user accounts. 

If you discover a security vulnerability (such as a Cross-Site Scripting (XSS) risk during document parsing, malicious file handling in EPUB/PDF unpackers, or dependency vulnerability):

1. **Do not create a public issue on GitHub.**
2. Send a private advisory through GitHub's [Security Advisories](https://github.com/saptarshidas578/speed_reader/security/advisories) tab or contact the maintainer directly via [GitHub Profile](https://github.com/saptarshidas578) or [LinkedIn](https://www.linkedin.com/in/saptarshi-das-3255673a1/).
3. Include detailed steps to reproduce the vulnerability, including sample text or files if applicable.

We take security issues seriously and will respond promptly to review, validate, and remediate any confirmed concerns.
